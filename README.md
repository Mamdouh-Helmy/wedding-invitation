# دعوة زفاف إلكترونية فاخرة — «إصدار الزفاف»

دعوة زفاف تفاعلية بالعربية بالكامل (RTL) تبدأ بظرف ورقي وختم شمعي، ثم بطاقة دعوة يمكن قلبها وكشف بطاقة تفاصيل ثانية، ثم صفحة احتفال كاملة بقصة العروسين والعد التنازلي والبرنامج وتأكيد الحضور.

## التقنيات
- Next.js 15 (App Router) وReact 19 وTypeScript
- CSS عادي بدون مكتبات UI أو مكتبات حركة خارجية للحفاظ على سرعة التحميل
- خطوط Google عبر `next/font`: Aref Ruqaa للأسماء والعناوين والأرقام، وTajawal للنصوص المساعدة
- رسومات SVG مرسومة داخل المشروع (الختم الشمعي، الغصن النباتي، مشهد الحديقة الليلي، الفلوكة، الخريطة)

## التشغيل
```bash
npm install
npm run dev
npm run build && npm start
```
المتطلبات: Node.js 18.18 أو أحدث. الحزم المطلوبة: `next` و`react` و`react-dom` فقط، بالإضافة إلى حزم التطوير الخاصة بـ TypeScript.
أول `npm run build` يحتاج اتصالًا بالإنترنت لتحميل الخطوط.

## تعديل البيانات
كل النصوص المتغيرة (الأسماء والموعد والمكان والبرنامج والقصة ورقم واتساب ومسار الموسيقى) في `data/invitation.ts`. أما التواريخ المعروضة فتُحسب تلقائيًا من حقل `date` في الملف نفسه.

## هيكل المشروع
- `app/` التخطيط والأنماط والصفحة الرئيسية
- `components/` كل قسم في ملف مستقل:
  - `Stage` الظرف والبطاقة وأزرار القلب والتفاصيل، ويستخدم `CardFront` و`CardBack` و`DetailsCard`
  - `Hero` و`Story` و`Countdown` و`Details` و`Evening` و`Rsvp` و`Footer` أقسام الصفحة
  - `Nav` و`FloatingActions` الشريط العلوي وأزرار واتساب والموسيقى
  - `Art` كل الرسومات والأيقونات، و`Reveal` لظهور العناصر عند السكرول
- `hooks/` المنطق القابل لإعادة الاستخدام: `useAudio` و`useCountdown` و`useScrollState`
- `lib/` دوال مساعدة: `format.ts` لتنسيق التاريخ بالعربية، و`contact.ts` لروابط واتساب وملف التقويم
- `public/audio/` ملف الموسيقى

## كيف تعمل التجربة
1. **الظرف:** الضغط على الختم يكسره ويفتح الغطاء بحركة ثلاثية الأبعاد، فتصعد البطاقة ثم تكبر إلى حجمها الكامل بينما يختفي الظرف.
2. **قلب البطاقة:** زر «اقلب البطاقة» يدير البطاقة 180 درجة لتظهر الواجهة الخلفية بالمونوغرام والرسالة.
3. **بطاقة التفاصيل:** زر «اعرض التفاصيل» يفتح بطاقة ثانية بجانب البطاقة على الشاشات العريضة وتحتها على الموبايل، وفيها البرنامج والموقع وزر تأكيد الحضور.
4. **الموسيقى:** المتصفحات تمنع التشغيل التلقائي، لذلك تبدأ الموسيقى من ضغطة الختم، ويمكن إيقافها وتشغيلها من الزر العائم.
5. **نموذج تأكيد الحضور:** لا يوجد خادم، فعند الإرسال تُجمَّع إجابة الضيف في رسالة واتساب جاهزة.
6. **أضف إلى التقويم:** يولّد ملف `.ics` مباشرة من بيانات الدعوة.

## ملاحظات التنفيذ
- أحجام النص داخل البطاقة تتناسب مع عرضها عبر وحدات `cqw`، مع حدود دنيا مقروءة، فتبقى نسبة البطاقة ثابتة بدون قص ولا تمرير أفقي.
- الحركة تعتمد على `transform` و`opacity` غالبًا، ويُحدَّث موضع السكرول مرة واحدة لكل frame في متغير CSS واحد `--sy`.
- لا يُستخدم تباعد الأحرف مع النص العربي حتى لا تنفصل الحروف.
- تُحترم تفضيلات `prefers-reduced-motion`.
- المشاهد المرسومة بالـ SVG بديلة عن الصور الفوتوغرافية في تصميم الواجهة. لاستبدالها بصور حقيقية ضع الصور في `public/images` واستخدمها في `Hero` و`Story` و`Footer`.
- ملف الموسيقى الحالي مولّد برمجيًا ويمكن استبداله بأي ملف مرخّص بنفس المسار.
- جميع البيانات وهمية.
- لا توجد تعليقات داخل الكود عن قصد، وهذا الملف هو مرجع الشرح.
